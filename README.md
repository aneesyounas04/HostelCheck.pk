# HostelCheck.pk 🏠

### Affordable Hostels for Students

**Tagline:** Find affordable, verified hostels near your university in 5 minutes.

---

## 🚀 Project Overview
HostelCheck.pk is a student‑focused platform where university students can easily find and review hostels in Rawalpindi/Islamabad.  
Our main focus is **affordability, transparency, and verified reviews**.

---

## 🎯 Problem
Students waste 1–2 weeks searching for hostels on Facebook groups.  
Existing platforms (Zameen, OLX) are expensive and not student‑friendly.

---

## 💡 Solution
A simple website where students can:
- Search hostels by area, rent, type, and facilities.
- View hostel profiles with real photos, rent, and location.
- Read verified student reviews (cleanliness, food, WiFi, owner behavior).
- Contact hostel owners directly via WhatsApp.

---

## 👥 Target Users
- New and current students of QAU, COMSATS, NUST, and other universities in Islamabad/Rawalpindi.
- Budget range: Rs. 8,000 – 20,000 per month.

---

## 🔑 Key Features
- **Search & Filter** by area, rent, type, facilities.  
- **Hostel Profile** with photos, rent, Google Maps location, mess menu.  
- **Verified Reviews** only from students.  
- **Affordability Badge** for hostels under Rs. 12,000.  
- **Owner Dashboard** to update hostel details.

---

## 🛠️ Tech Stack
- **Frontend:** React (Create React App), Tailwind CSS  
- **Backend & Database:** Supabase  
- **Image Uploads:** Cloudinary  
- **Maps Integration:** Google Maps API  
- **Auth:** Google Login
